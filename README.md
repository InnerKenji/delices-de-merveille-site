# Les Délices de Merveille · site web

Site vitrine statique (HTML, CSS et JavaScript sans dépendance), hébergé sur Vercel.

## Mettre à jour l'offre du jour
Dans `index.html`, modifier le tableau `OFFRE_DU_JOUR` en haut du script : nom, prix (laisser `''` si pas de prix, le bouton propose alors de demander le prix sur WhatsApp), image et badge.

## Images
Les images sont dans `img/` (format WebP, environ 300 px de large).
